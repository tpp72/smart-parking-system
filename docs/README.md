# เอกสารของโครงงาน

สารบัญเอกสารทั้งหมด พร้อมบอกว่าฉบับไหนใช้อ้างอิงได้ และฉบับไหนเก็บไว้ดูประวัติเท่านั้น

> เอกสารเหล่านี้เพิ่งถูกนำเข้า git เมื่อ 2026-09-28 — ก่อนหน้านั้น `/docs` อยู่ใน `.gitignore`
> ทำให้ไม่มีประวัติการแก้ไขของช่วงก่อนวันนั้น

## ใช้อ้างอิงได้ (ปัจจุบัน)

| เอกสาร | คืออะไร |
| --- | --- |
| [project-plan.md](project-plan.md) | **Source of Truth** — requirement และกฎธุรกิจทั้งหมด · ทุกการตัดสินใจที่เปลี่ยนกฎถูกบันทึกพร้อมวันที่ไว้ในนี้ |
| [PRODUCT.md](PRODUCT.md) | Product / UX contract ที่ใช้กับงาน UI |
| [TEST_COVERAGE.md](TEST_COVERAGE.md) | จับคู่ requirement กับไฟล์เทสต์ (ตารางยังตามไม่ทันฟีเจอร์ล่าสุด — ดูหมายเหตุในไฟล์) |
| [UAT_CHECKLIST.md](UAT_CHECKLIST.md) | รายการทดสอบด้วยมือ / edge case |
| [POST_FIX_AUDIT.md](POST_FIX_AUDIT.md) | ผลตรวจรอบล่าสุด พร้อมสถานะของแต่ละข้อ |

ถ้าต้องการสถานะจริง ณ ปัจจุบัน ให้ดู `project-plan.md` และ `POST_FIX_AUDIT.md`

## ข้อตกลงในการเขียนเอกสาร

- เมื่อกฎธุรกิจเปลี่ยน ให้บันทึกลง `project-plan.md` พร้อม **วันที่ตัดสินใจ** และเหตุผล ไม่ใช่เขียนทับของเดิมเฉย ๆ
- เอกสารที่หมดอายุแล้วไม่ลบทิ้ง แต่ใส่ป้าย `SUPERSEDED` ที่หัวไฟล์พร้อมชี้ว่าให้ไปดูที่ไหนแทน
- **ห้ามใส่ค่าความลับจริงลงเอกสาร** (รหัสผ่าน · API key · connection string) — อ้างถึงได้ว่ามีปัญหาตรงไหน แต่ปิดค่าด้วย `***`
